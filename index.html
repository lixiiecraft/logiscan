PROTÓTIPO • V1

LogiScan ▥

Leia o código de barras linear de uma etiqueta e gere um QR Code com o mesmo conteúdo.

1. Capturar etiqueta

A leitura é limitada a códigos de barras lineares; QR Codes presentes na etiqueta são ignorados.

Pronto para começar.

2. Conferir código

Confira cada caractere antes de gerar o QR. Não acrescente espaços.

3. QR Code gerado

Teste com dados fictícios. A leitura pelo coletor depende da configuração do sistema da empresa.

Privacidade: esta versão processa a leitura no próprio navegador e não envia os códigos para um servidor. As bibliotecas são carregadas de uma CDN. A câmera exige HTTPS ou localhost.
